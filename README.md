# LLMs Judge You Harshly When You Speak Figuratively

This anonymous repository contains the code and data accompanying our ICLR submission, **“LLMs Judge You Harshly.”**

The materials provided here are intended to support the reproducibility and evaluation of the work presented in the paper. The repository will be updated with detailed instructions for setting up the environment, running the experiments, and reproducing the reported results.

## Repository contents

- Experimental code
- Data and supporting resources
- Instructions for reproducing the results

## Anonymity

This repository has been prepared for double-blind peer review. Author names, affiliations, and other identifying information have been omitted. Questions regarding the materials should be submitted through the official OpenReview discussion forum.
